# Smart Recaps Demo

Smart Recaps is a demo product that turns meetings, project updates, pull requests, and planning docs into audience-specific recaps with citations, decisions, owners, and follow-ups.

## Demo workflows

- Product lead weekly digest from Linear, Drive, and GitHub.
- Design critique recap with decisions and open questions.
- Engineering handoff that summarizes PRs, risks, and next actions.

## Repo shape

- `src/recap-contract.ts` defines the recap schema.
- `src/source-citations.ts` normalizes references from docs, issues, and PRs.
- `docs/demo-script.md` gives a narrated demo flow.
