# Citation Side Panel Design

## Purpose
The citation side panel keeps Smart Recaps inspectable. Readers can expand any claim and see source type, title, excerpt, and link without leaving the recap.

## States
- Default: first citation selected.
- Empty: explain that no trustworthy source was found.
- Low confidence: show available sources and ask for review.
- Multi-source: group by meeting, document, Linear, and GitHub.
